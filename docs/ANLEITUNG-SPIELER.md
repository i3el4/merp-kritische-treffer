# MERS – Kurzanleitung für Spieler

## Start

1. Rolle **Spieler** wählen.
2. **Kampagne** (und ggf. mit **Kampagnen-ID** beitreten) + **Charakter** wählen → **Starten**.
3. Profil-Icon oben rechts: Rolle oder Charakter später wechseln.

**Tabs:** Kampf · Status · Charakter

---

## Kampf in 7 Schritten

| Schritt | Aktion |
|--------|--------|
| 1 | **Waffenart** antippen (bei Biss/Klaue/…: Grösse wählen) |
| 2 | **Ziel(e)** antippen – Gegner = Angriffsziele (mehrere möglich) |
| 3 | **Angriffswert** eintragen |
| 4 | **Treffer ermitteln** → TP + ggf. Krit-Kategorie |
| 5 | Bei Krit: **Wurf** eintragen → **Kritischer Treffer ermitteln** |
| 6 | Optional: **… TP anwenden** – Schaden auf Ziele buchen |
| 7 | **Zurücksetzen** für neuen Angriff |

**DB** der Ziele steht **unter** den Icons, nicht im Namen.

---

## Status & Charakter

- **Status:** deine TP, RK, DB, Effekte (benommen, K.O., …).
- **Charakter:** kompakte Übersicht deiner Figur.
- Gegner und Kampfrunde steuert der **Spielleiter**.

---

## Optional

- **Nebentreffer** / **Patzer:** Bereich aufklappen im Kampf-Tab.
- **Audio:** Profil → Musik / Lautstärke / TTS.

---

## Wenn etwas hakt

Seite **hart neu laden** (Strg+F5 / Cmd+Shift+R). Bei Sync-Problemen: Kampagnen-ID vom SL prüfen.
